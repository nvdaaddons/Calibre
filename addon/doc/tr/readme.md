# Calibre #
  
* Yazar: Javi Dominguez
* [Kararlı sürümü][1] indir
* [Geliştirici sürümünü][2] indir
  
 Eklenti, Calibre e-kitap yönetimi yazılımının arayüzü için bazı erişilebilirlik geliştirmeleri sunar

* F10 tuşuyla odağı araç çubuğuna getirebilirsiniz. Daha sonra araç çubuğunda standart dolaşım tuşlarıyla dolaşabilirsiniz (tab ve ok tuşları), enter tuşuyla öğeyi etkinleştirebilir, uygulama tuşuyla içerik menüsünü görüntüleyebilir ve escape tuşuyla araç çubuğundan çıkabilirsiniz.
* Üzerinde bulunduğunuz kitabı Google'da aratmak için F12 tuşuna basın
* Üzerinde bulunduğunuz kitaplık görünümündeki kitapların sayısını ve seçilen kitapların sayısını öğrenmek için NVDA+alt+end tuşlarına basın
* Üzerinde bulunduğunuz sütunun ayarlarıyla ilgili içerik menüsünü açmak için NVDA+kontrol+h tuşlarına basın
* Kitaplık görünümünde kitap bilgisini öğrenmek için I tuşuna basın.
 
Calibre açıkken kısayol tuşları NVDA tercihler menüsü>girdi hareketleri iletişim kutusundan özelleştirilebilir. Ayrıca tercihlerde NVDA'nın kitaplıkta tablo başlıklarını okumasını satırlar ve sütunlar, sadece sütunlar veya hiçbiri olacak şekilde değiştirebilirsiniz.
 
 Daha fazla kısayol tuşu öğrenmek için [Calibre kullanım kılavuzuna][3] göz atın.
