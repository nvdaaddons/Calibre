# Calibre #
  
* Автор: Javi Dominguez
* Завантажити [стабільну версію][1
* Завантажити [версію в розробці][2]
  
 Додаток NVDA з деякими покращеннями доступності для інтерфейсу Calibre eBook Management

* F10 переносить фокус на панель інструментів. Потім ви можете переміщуватися по ньому за допомогою стандартних клавіш (tab і стрілки); enter для активації елемента та ключових програм для відображення контекстного меню; escape, щоб вийти з панелі інструментів.
 
Натискання клавіш можна налаштувати в «Параметрах» NVDA > Жести вводу, коли відкрито calibre. Також в налаштуваннях можна визначити спосіб, у який NVDA читає заголовки таблиць у бібліотеці (рядки та стовпці, лише стовпці чи жодного).
 
 Перегляньте [документацію Calibre][3], щоб дізнатися більше про комбінації клавіш.
