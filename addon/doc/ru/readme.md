* Автор: Javi Dominguez
* Загрузить [стабильную версию][1]
* Загрузить [разрабатываемую версию][2]
  
 Дополнение NVDA для некоторого улучшения доступности интерфейса управления электронными книгами Calibre

* F10 перемещает фокус на панель инструментов. Затем вы сможете перемещаться по ней стандартными клавишами (tab и стрелки); Активировать элемент клавишей enter и для отображения контекст-меню клавишей applications; escape для выхода из панели инструментов.
* F12 найти текущую книгу в Google
* NVDA+Alt+End показать общее количество книг в текущем представлении библиотеки и количество выбранных книг
* NVDA+Control+H открыть контекстное меню для настройки текущего столбца
* I в режиме просмотра библиотеки считывается информация о книге.
 
Комбинации клавиш можно определить в настройках NVDA > Жестах ввода, когда calibre открыт. Также в настройках можно определить, как NVDA считывает заголовки таблиц в библиотеке (строки и столбцы, только столбцы или ничего).
 
 Ознакомьтесь с [документацией Calibre][3], чтобы узнать больше сочетаний клавиш.
